# Lauren's Designs — HTML/CSS portfolio starter

This is a responsive, static recreation starter for a UX/web design portfolio. It was assembled from the content and visual direction discussed in ChatGPT, plus the available public link lookup; it is **not an exact source-code export from Wix**.

## Files
- `index.html` — all page content and sections
- `style.css` — responsive layout and styling
- `script.js` — small mobile navigation interaction and footer year
- `assets/` — add your own images, logos, project screenshots, and portrait here

## Preview
Open `index.html` in a browser. The Google Fonts import requires an internet connection; the page falls back to system fonts if unavailable.

## Before publishing
1. Replace the illustrated hero and the CSS transit dashboard with your real project visuals if you prefer.
2. Update the project descriptions and add case-study links.
3. Replace `hello@laurenesdesigns.com` with your real contact email.
4. Add your social links and any actual client logos/testimonials you have permission to use.
5. Check all copy, then test at desktop and mobile sizes.

This is a static website. Wix-specific CMS, forms, analytics, SEO settings, and publishing features are not automatically transferred.
